Base Sepolia

An agent that never forgets who paid.

Paid per step in USDC on Base. Everything it knows lives in one memory file.

— records in memory
scroll

01 — metering

Every step is paid.

Scope is free. It reads the contract, states what it will look at, and stops. Findings, patch and verify are sold one at a time — each with its own price, its own invoice, its own receipt.

The buyer pays on Base, and the agent commits a hash of its answer next to the payment. Money and output are recorded in the same place, in the same order they happened.

02 — memory

Restart it. It remembers.

Kill the process and start a new one. It reads the memory file, resumes at the recorded step, and never redoes work that was already paid for. A buyer who has paid before gets credit — the next step runs before the invoice clears.

03 — failure

Delete the memory.

Nothing on chain tells the agent it has met this buyer. It invoices the same address again for work already paid, and the second payment lands next to the first — two receipts, one answer, no way to tell from the ledger which one was owed.

04 — the split

The chain remembers the money. Not the reason.

Base holds payments and output hashes. It does not hold findings, prices, cost history, or trust. A memo is opaque without the memory that wrote it: the same bytes mean "paid step 3 for a trusted buyer" or nothing at all.
